# Video script (three minutes)

Use the same flow as the live demo. It is short enough to rehearse and leaves
time for the judges to ask about the evidence.

| Time | Screen | Voice-over |
| --- | --- | --- |
| 0:00–0:25 | Home | “A QR merchant payment can hide an unlicensed cash-out. The usual response is to limit every merchant, but that harms honest businesses. Jachai reviews the few shops that need context. Everything shown here is synthetic.” |
| 0:25–0:50 | Alert queue | “This is not a fraud list. It is a ranked human-review queue. Each case combines payment, shop and payer–shop network evidence.” |
| 0:50–1:25 | Case view | “Here are the three signals, the top reasons, the timeline and linked shops. The analyst—not the model—chooses clear, monitor, educate, convert, restrict or escalate, always with a written reason.” |
| 1:25–1:45 | Merchant notice | “The notice is polite Bangla, explains the evidence and gives a route to appeal. No merchant is automatically blocked and merchant text is never sent to an LLM.” |
| 1:45–2:20 | Simulator | “We replay the same synthetic month under five policies. This exposes the trade-off between stopping misuse, analyst capacity and harm to honest merchants. It is a diagnostic, not a forecast.” |
| 2:20–2:50 | Trust | “We report the difficult result too: rules rank better on the normal synthetic world. In the configured non-round evasion test, Jachai is more robust because shop and network evidence still contribute. Real data is needed before any production claim.” |
| 2:50–3:00 | Home | “Jachai: don’t restrict every merchant; review the few that need context. A human decides every action.” |

Recording tips: record at laptop width; use the step-by-step Demo walkthrough
only as a navigation aid; rehearse once with the API unavailable to confirm the
bundled synthetic demo fallback still opens.
