# Third-party components

Every external library, model, API, dataset and service used by Jachai, with its
licence (Rulebook HR 4.4, 9.2). Add a row **in the same commit** that introduces
the component.

This register covers every dependency, action, model and service selected
directly by the project. Exact frontend resolution—including each transitive
package's SPDX licence—is recorded in `frontend/package-lock.json`; exact Python
resolution is recorded by installed distribution metadata after `make install`.
Transitive components are not presented as project-selected models, APIs or
datasets.
